README

Эта программа рисует прямоугольный треугольник в консоли. Высота h вводится пользователем, по условию h >= 3.

Вот функция, которая рисует фигуру:

public static void printTriangle(int h) {
if (h < 3) {
System.out.println("Высота должна быть >= 3");
return;
}

Здесь я сначала проверяю параметр h. Если он меньше 3, программа сообщает об ошибке и выходит, так как по заданию высота не может быть меньше 3.

System.out.println("*");
for (int i = 2; i < h; i++) {
System.out.print("|");
for (int j = 0; j < i - 2; j++) {
System.out.print(" ");
}
System.out.println("\\");
}

Эта часть рисует верхнюю звездочку и средние строки. Я использовал вложенный цикл: внешний цикл идет по строкам, а внутренний печатает пробелы. Количество пробелов равно i - 2, чтобы получить наклонную линию.

System.out.print("*");
for (int i = 0; i < h - 2; i++) {
System.out.print("-");
}
System.out.println("*");
}

В конце рисуется нижняя строка. Цикл печатает дефисы. Их количество равно h - 2, потому что два символа по краям заняты звездочками.

В функции main я просто считываю h с клавиатуры и вызываю printTriangle(h).
